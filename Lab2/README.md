# Antivirus Daemon

A Bash script that actively monitors a specific directory for suspicious files. When triggered, it checks for malicious file extensions and specific keywords, automatically moving flagged files to a quarantine folder.

## Usage
There are two scripts here:

### 1. Antivirus monitoring script:

This script requires exactly three arguments to run:

```bash
./antivirusd.sh <target_directory> <quarantine_directory> <sleep_seconds>
```

**Arguments:**
1. `target_directory`: The folder you want to monitor.
2. `quarantine_directory`: The folder where malicious files will be moved.
3. `sleep_seconds`: The delay (in seconds) between directory checks.

### 2. Restore script

This script requires exactly 2 arguments to run:

```bash
./restore.sh <target_directory> <quarantine_directory>
```

**Arguments:**
1. `target_directory`: The folder you want to restore files to.
2. `quarantine_directory`: The folder where malicious files exist.

### Using the Makefile (For the antivirus script **ONLY**)
If you are using the included `Makefile`, you can run the script with default values by simply typing:
```bash
make run
```
To clean up the temporary files generated by the script, use:
```bash
make clean
```
To ovveride default values for the arguments, use for example:
```bash
make run WATCH_DIR=/tmp/downloads SLEEP_SECS=10
```

## How It Works

### - Antivirus script:
In the first run, the `directory-info.last` is created and populated, then we run the checks of the antivirus and sleep then we enter the infinite loop that keeps on checking if the files changed and if yes it runs the checks of the antivirus again, else it sleeps.

### - Restore script:
Show the files inside the quarantine directory numbered, and if there are no files it exits the script. If there are files, it asks the user for the number of the file then it prints another menu of options for the user to choose from.

### 1. Extension Checking
the find command gets the name of files from the dir and checks its extensions. `-type f` means that the type is files, `-o` is for OR

### 2. Content Checking
-r for recursive, -i for ignore case (case-insensitive), -l only prints the file name that matches, -E for extended regular expressions (what makes us use \ and it can be understood as 'OR')

### 3. Quarantine Process
checks that the file is not empty, reads every line from the file, move file to quar_dir

### 4. The Monitoring Loop
The infinite loop starts by comparing the temp files that store the content of the dir, if they are the same, sleep again, if they are different then make the new file the old one and check the files (antivirus script).

## Temporary Files

The script generates the following temporary files during execution. (These can be removed using `make clean`):
* `directory-info.last` - Stores the previous state of the directory.
* `directory-info.new` - Stores the current state of the directory for comparison.
* `mal_files` - A temporary list of flagged files waiting to be quarantined.

### Cron Job:
This automates the antivirus checking instead of the sleep argument we used before in the script
## Usage:
- Run this to open cron table:
```bash
crontab -e
```
- Add this to the cron table file (modify the paths to your use):
`* * * * * sleep 23 && ~/Documents/OS-Labs/Lab2/antivirus-cron.sh ~/Documents/test ~/Documents/quar`
    - Note: You must use the full path
    - Note: "*\*\*\*\*\*" tells cron to execute at 00 seconds of every minute, we then use sleep because cron cant handle seconds.
